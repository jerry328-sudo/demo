此仓库托管了一个个人演示登录页面和多个交互式可视化项目。

## 开始使用

在现代浏览器中打开 `index.html` 以查看展示。为了获得最佳效果，请通过简单的静态Web服务器提供站点：

```bash
python3 -m http.server 8000
```

然后导航到 http://localhost:8000/。

## 演示项目

- **星际旅行燃料计算器** - 基于相对论火箭方程的燃料计算工具
- **洛伦兹时空图** - 基于 Three.js 的闵可夫斯基时空图交互演示
- **布里渊区采样** - 第一布里渊区可视化工具
- **[切尔诺贝利反应堆模拟器](demos/chernobyl-core/index.html)** - RBMK 堆芯三维可视化、自由操作与事故时间线，支持中英文；采用定性教学模型，Three.js 与字体通过 CDN 加载
- **CNN 卷积核可视化** - Conv1d 交互式可视化实验
- **CartPole 强化学习** - 4→8→2 小网络与 REINFORCE；对比未训练、已训练示例和自己的最优策略，区分探索得分与独立评估
- **几何即引力** - 从度规到爱因斯坦场方程的交互式相对论课堂
- **GNN 神经元实验** - 从图节点、邻居聚合到单个神经元的交互演示
- **图神经网络可视化入门** - 消息传递、GCN、GraphSAGE、GAT、GIN 与训练超参数实验
- **归纳式 GCN 测试图扩展** - 固定训练权重，逐步接入两篇论文和一张新引用子图，比较原有论文的预测变化
- **注意力机制算法可视化** - 调整输入，观察点积、加性、自注意力、交叉注意力、多头、图与通道空间加权的计算

## 首页目录维护

首页按「物理与宇宙」「人工智能」「效率工具」分组。新增条目时，在 `index.html` 对应的 `.project-list` 中添加 `.project-row`，保留标题、说明和链接；可通过 `data-keywords` 补充搜索别名。分类数量由脚本按实际条目计算，搜索与类别筛选可同时使用。禁用 JavaScript 时仍显示完整目录。

首页样式限定在 `.lab-home` 下，避免影响使用共享样式的演示页。运行 `npm run check` 可检查首页脚本语法；`npm run build` 仅用于 CI/远端确认静态站点无需构建。

## CartPole 训练与验证

入口保留为 `demos/CartPole.html`，无需额外依赖，支持直接双击 HTML 或通过静态服务器打开。浏览器按顺序加载普通脚本，不依赖 `file://` 下会受限的 ES 模块。每 8 回合汇总 REINFORCE 的未来奖励，标准化后使用 Adam 更新同一个 58 参数网络；每 40 回合在独立环境中评估 10 回合，仅按评估平均分保留最优权重。播放独立于训练，并按固定的 0.02 秒时间步运行。

开始训练时自动查看“正在学习的策略”，每次权重更新都会同步到网络图与小车；“我的最优策略”另存评估快照。连线用固定映射 `0.7 + 4√|w|` CSS 像素绘制，各层和各策略共用尺度，不随单帧最大值归一化。默认跟踪变化最大的连接，支持点击、触摸或方向键固定查看其初始权重、当前权重与差值；节点明暗单独表示激活值，播放不会改变固定策略的线宽。

- `npm run check:cartpole`：物理参考值、梯度差分、终止条件、独立评估、多种子学习效果与示例权重复现。
- `npm run train:cartpole`：从固定种子 42 训练 400 回合，重新生成 `demos/cartpole/example.js`。示例是这套算法的训练输出。
- 对比原版：均训练 400 回合，训练种子 1–5，每个选中模型在同一组 20 个未参与训练的初始状态上测试，原版平均 371.57/500，新版 491.28/500。旧版按单次探索回合选权重，新版按独立评估均分选择；比较的是演示的完整训练与选择流程。
- 内置示例在独立种子 20000 的 100 回合测试中平均 500/500。这是给定初始状态分布的结果，不代表所有扰动下都成功。环境沿用原版高斯随机初值，失败步奖励为 0，存活步奖励为 1；区别于 Gymnasium 的均匀初值和失败步也给 1 的计分。
